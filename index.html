Capabilities

Five agents. One prompt.

Methoryn routes tasks through specialised agents automatically — you just type what you want.

🤖

Multi-Agent Execution

Five specialised agents work as one system: Groq plans and orchestrates, Cloudflare runs the tools and libraries, Gemini handles research and images, Mistral writes and debugs code, and NVIDIA double-checks the result.

📁

Files & Code

Read, write, move, and delete files. Write and run Python scripts. Execute shell commands. Export to .txt, .md, .html, .csv, .docx, or .pdf.

📧

Gmail & Google Drive

Read, search, send, and delete emails. List, upload, and share Drive files — all directly from your terminal.

📊

Google Workspace

Create and edit Google Docs, Sheets, Slides presentations, Forms, and Calendar events with a single prompt.

🖼️

Image Generation

Generate AI images with Gemini (/image). Saves to Desktop and works directly inside Slides presentations.

🌐

Web & Search

Search the web with /search and fetch any URL with /fetch — no browser needed.

💾

Session Memory

Conversation context automatically saves on quit and reloads on next launch. Pick up exactly where you left off.

🔑

Bring Your Own Keys

Set and manage API keys directly inside the app with /account. No manual .env file editing required.

⚡

Slash Commands

Type / to open the command palette with 24 slash commands for common tasks — no prompting needed.

What You Need

Four keys. All with free tiers.

Layers 1–4 (Groq, Cloudflare, Gemini, Mistral) are required to run — each offers a generous free tier. NVIDIA adds quality control and is optional.

GROQ_API_KEY Required
Layer 1 — conversation & orchestration — console.groq.com Free tier available
CLOUDFLARE_API_KEY Required
Layer 2 — library & task-plan execution (needs CLOUDFLARE_ACCOUNT_ID) — developers.cloudflare.com Free tier available
GOOGLE_API_KEY Required
Layer 3 — Gemini multimodal & research — aistudio.google.com 1M tokens/month free
MISTRAL_API_KEY Required
Layer 4 — coding agent — console.mistral.ai ~1B tokens/month free
NVDA_API_KEY Optional
Layer 5 — NVIDIA quality control & review — build.nvidia.com Free tier available
Google OAuth Optional
Gmail, Drive, Docs, Sheets, Calendar — sign in with /account Free
Platform

Windows, macOS & Linux.

Requires Python 3.13+. Works on Windows, macOS, and Linux. The taskbar progress animation is Windows-only — everything else is fully cross-platform.

✓ Windows 10 / 11
✓ macOS 12+ (Intel & Apple Silicon)
✓ Linux (Ubuntu, Debian, Fedora, Arch)
✓ Python 3.13+

On macOS, install via brew install python@3.13 then pip install Methoryn. On Linux, use your system Python 3.13+ or uv. The taskbar progress bar uses a Windows-only API and is silently skipped on other platforms.
