Capabilities

One agent. Everything you need.

ANVYL routes tasks through specialised agents automatically — you just type what you want.

🤖

Multi-Agent Execution

Groq handles your primary task with full tool access. Gemini sub-agents run parallel research and generation in the background.

📁

Files & Code

Read, write, move, and delete files. Write and run Python scripts. Execute shell commands. Export to .txt, .md, .html, .csv, .docx, or .pdf.

📧

Gmail & Google Drive

Read, search, send, and delete emails. List, upload, and share Drive files — all directly from your terminal.

📊

Google Workspace

Create and edit Google Docs, Sheets, Slides presentations, Forms, and Calendar events with a single prompt.

🖼️

Image Generation

Generate AI images via Pollinations.ai with /image. Saves to Desktop and works directly inside Slides presentations.

🌐

Web & Search

Search the web with /search and fetch any URL with /fetch — no browser needed.

💾

Session Memory

Conversation context automatically saves on quit and reloads on next launch. Pick up exactly where you left off.

🔑

Bring Your Own Keys

Set and manage API keys directly inside the app with /keys. No manual .env file editing required.

⚡

Slash Commands

Type / to open the command palette with 25+ shortcuts for common tasks — no prompting needed.

What You Need

Only one key is required.

All providers below have a free tier. Groq is the only mandatory one — everything else unlocks additional capabilities.

GROQ_API_KEY Required
Main task agent — console.groq.com Free tier available
GOOGLE_API_KEY Optional
Gemini sub-agents — aistudio.google.com 1M tokens/month free
Google OAuth Optional
Gmail, Drive, Docs, Sheets, Calendar — sign in with /sign-in Free
MISTRAL_API_KEY Optional
Chat primary — console.mistral.ai ~1B tokens/month free
Pollinations.ai Optional
Image generation via /image Completely free — no key needed
+ 4 more providers Optional

Platform

Windows & macOS.

Requires Python 3.13+. Works on Windows and macOS. The taskbar progress animation is Windows-only — everything else is fully cross-platform.
