Setup

Installation

ANVYL installs as a standard Python package. Python 3.13 or newer is required.

1

Install Python 3.13+

Download from python.org. Make sure to check "Add Python to PATH" during installation on Windows.

2

Install ANVYL

Open a terminal (PowerShell on Windows, Terminal on Mac) and run:

pip install anvyl
3

Launch ANVYL

Run the anvyl command. The first time you launch it, a setup screen will appear to walk you through adding your API keys.

anvyl
4

Add your Groq API key

Go to console.groq.com, sign up for free, and copy your API key. Paste it into the setup screen and click Continue.

5

Start using ANVYL

Type any prompt and press Enter. Or type / to open the command palette.

# Pass a prompt directly from your terminal anvyl "summarize my last 5 emails" anvyl "create a Python script that renames all files in a folder"

ℹ  To update ANVYL to the latest version at any time, run: pip install --upgrade anvyl

Setup

Google Sign-In

Google sign-in is required during the setup screen. It unlocks Gmail, Drive, Docs, Sheets, Slides, Forms, and Calendar. Your credentials are stored locally — ANVYL never sends them anywhere.

1

Click "Sign in with Google" in the setup screen

ANVYL opens a browser tab automatically. Sign in with your Google account and grant the requested permissions.

2

Token saved automatically

After signing in, the OAuth token is saved to ~/.anvyl/google_token.json on your machine. Future sessions sign in silently.

3

Re-authenticate or sign out anytime

Use /sign-in to switch accounts or refresh your token. Use /sign-out to revoke access.

Configuration

Managing Keys

Use the /keys slash command to open the key editor at any time — no file editing required. Keys are stored locally at ~/.anvyl/byok.json and never leave your machine.

# Open the full key editor UI /keys # Keys are stored at: ~/.anvyl/byok.json (Mac/Linux) C:\Users\you\.anvyl\byok.json (Windows)

You can also set keys via environment variables or a .env file in the project root — but the in-app editor is the recommended approach.

Guidelines

Usage Guidelines

What ANVYL is for

  • Automating repetitive tasks — file management, document creation, email summaries
  • Writing and running code on your local machine
  • Interacting with your Google Workspace on your behalf
  • Research, web search, and content generation
  • Any task you'd normally do manually in a terminal or browser

What ANVYL should not be used for

  • Accessing accounts, files, or systems you do not own or have permission to use
  • Sending unsolicited emails or automating spam
  • Generating malicious code, exploits, or harmful content
  • Any activity that violates the terms of service of the connected providers (Groq, Google, etc.)

Be careful with

  • Shell commands (/run) — ANVYL executes them directly on your machine
  • File writes (/write) — changes are immediate and may overwrite existing files
  • Gmail actions — sending or deleting emails is permanent
  • API key usage — each prompt consumes tokens from your provider accounts
Guidelines

Privacy

ANVYL runs entirely on your machine. Here is exactly what leaves your device:

WhatSent toWhy
Your prompts and conversation history Groq / Gemini / Mistral APIs To generate AI responses
Google OAuth token Google OAuth servers To authenticate your Google account
Image generation prompts Pollinations.ai To generate images via /image

ANVYL does not collect analytics, telemetry, or usage data. Your API keys are stored locally at ~/.anvyl/byok.json and are never transmitted to anyone other than the provider they belong to.
