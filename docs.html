Installation

Full installation reference for CORVUS — system requirements, platform-specific instructions, virtual environments, updating, and uninstalling.

Python

Python 3.13 or newer is required. Check your current version:

python --version # or python3 --version

If you see anything below 3.13, follow the platform-specific installation steps below before installing CORVUS.

Disk space

CORVUS and all its dependencies require approximately 150–250 MB of disk space depending on your platform and whether some dependencies are already installed.

Terminal

CORVUS uses the Textual terminal UI framework. It works best in modern terminals that support 24-bit color and unicode:

  • Windows: Windows Terminal (recommended), PowerShell 7, or cmd.exe
  • macOS: Terminal.app or iTerm2
  • Linux: Any modern terminal emulator (GNOME Terminal, Kitty, Alacritty, etc.)
Windows Terminal is available free from the Microsoft Store and provides the best experience on Windows. The built-in cmd.exe works but has limited color support.
Installation

Platform-Specific Installation

Windows

1

Download Python 3.13

Go to python.org/downloads and download the latest 3.13.x installer. Run the installer. On the first screen, check "Add Python to PATH" before clicking Install Now. Without this, CORVUS won't be found after installation.

2

Open PowerShell and install CORVUS

pip install CORVUS

If you see a "pip not found" error, try:

python -m pip install CORVUS
3

Verify

CORVUS --version

If this fails with "command not found", add Python's Scripts folder to your PATH. It is typically at C:\Users\YourName\AppData\Local\Programs\Python\Python313\Scripts.

macOS

1

Install Python via Homebrew (recommended)

# Install Homebrew if you don't have it /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" # Install Python 3.13 brew install python@3.13

Or download the macOS installer from python.org directly.

2

Install CORVUS

pip3 install CORVUS
3

Verify

CORVUS --version

If this fails, your Python bin path may not be on your shell's PATH. Add this to your ~/.zshrc:

export PATH="$(brew --prefix python@3.13)/bin:$PATH"

Linux (Ubuntu / Debian)

1

Install Python 3.13

sudo add-apt-repository ppa:deadsnakes/ppa sudo apt update sudo apt install python3.13 python3.13-pip python3.13-venv
2

Install CORVUS

pip3.13 install CORVUS
3

Verify

CORVUS --version
Advanced

Virtual Environments

Installing CORVUS in a virtual environment keeps it isolated from your global Python install. This is useful if you work on multiple Python projects with potentially conflicting dependencies.

1

Create a virtual environment

python -m venv CORVUS-env
2

Activate it

# Windows PowerShell CORVUS-env\Scripts\Activate.ps1 # Windows cmd.exe CORVUS-env\Scripts\activate.bat # macOS / Linux source CORVUS-env/bin/activate
3

Install CORVUS inside the venv

pip install CORVUS
4

Activate before each use

Each time you open a new terminal session, activate the virtual environment before running CORVUS. When active, your prompt will show the environment name in parentheses: (CORVUS-env).

Maintenance

Updating CORVUS

CORVUS is updated regularly with bug fixes, new commands, and improved AI routing. To upgrade to the latest version:

pip install --upgrade CORVUS

To check what version you currently have and what the latest is:

# Check your installed version CORVUS --version # Check what's available on PyPI pip index versions CORVUS

Updating dependencies

If a dependency update is needed (for example if a provider's Python client releases a security fix), you can force a full upgrade including all dependencies:

pip install --upgrade --upgrade-strategy eager CORVUS

Checking for updates automatically

CORVUS does not currently check for updates automatically on launch. We recommend checking periodically with pip install --upgrade CORVUS or watching the GitHub releases page for new versions.

After updating: Your API keys and Google token are stored separately in ~/.CORVUS/ and are never touched by the update process. You won't need to reconfigure anything.
Maintenance

Uninstalling CORVUS

To remove CORVUS from your Python environment:

pip uninstall CORVUS

This removes the CORVUS package but leaves your configuration files in place. To do a complete clean removal including your API keys, Google token, sessions, and outputs:

# Remove the CORVUS package pip uninstall CORVUS # Remove all CORVUS data — macOS / Linux rm -rf ~/.CORVUS # Remove all CORVUS data — Windows PowerShell Remove-Item -Recurse -Force "$env:USERPROFILE\.CORVUS"
This is permanent. Deleting ~/.CORVUS/ removes your saved API keys and Google OAuth token. You will need to reconfigure everything from scratch if you reinstall CORVUS later.

Removing a virtual environment

If you installed CORVUS in a virtual environment, simply delete the environment folder:

# Delete the virtual environment folder rm -rf CORVUS-env (macOS/Linux) Remove-Item -Recurse -Force CORVUS-env (Windows)
Help

Troubleshooting Installation

"CORVUS: command not found" after installing

Python's scripts directory is not on your system PATH. Find the scripts directory:

# Find where pip installs scripts python -m site --user-base

Add the bin (macOS/Linux) or Scripts (Windows) subdirectory of that path to your PATH environment variable, then restart your terminal.

"pip: command not found"

python -m pip install CORVUS

Using python -m pip bypasses PATH issues for pip itself.

Permission errors on macOS/Linux

Never use sudo pip install. It installs into the system Python, which can break system tools. Instead, install with the user flag:

pip install --user CORVUS

SSL certificate errors

This usually means your system certificates are out of date. On macOS, run the Install Certificates.command file in your Python installation folder. On Windows, ensure Windows Update is current.

ImportError or ModuleNotFoundError at launch

A dependency may have failed to install. Try reinstalling with:

pip install --force-reinstall CORVUS

Still stuck?

Open an issue or email us at CORVUS.cli@gmail.com with your platform, Python version, and the full error message.
