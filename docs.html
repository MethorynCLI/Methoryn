Getting Started

Installation & Setup

Everything you need to install ANVYL, connect your accounts, and run your first prompt — in under five minutes.

Prerequisites

System Requirements

ANVYL is a Python terminal application. Before installing, make sure your machine meets the following requirements.

Operating System

ANVYL runs on Windows, macOS, and Linux. It is tested primarily on Windows 11 and macOS Ventura and later. Most Linux distributions with Python 3.13+ available in their package manager will work fine.

Python Version

Python 3.13 or newer is required. Older versions of Python will not work because ANVYL uses type annotation syntax and standard library features introduced in 3.13. You can check your current Python version by running:

python --version # or on some systems: python3 --version

If you see anything lower than 3.13, follow the installation steps below to upgrade.

pip

pip is the Python package installer and comes bundled with Python 3.13. If for any reason it is missing, you can reinstall it with:

python -m ensurepip --upgrade

Internet connection

An internet connection is required during installation (to download the package from PyPI) and at runtime (to reach the AI provider APIs). ANVYL itself does not host any servers — it connects directly from your machine to the providers you configure.

Tip: On Windows, always open PowerShell or Command Prompt as a regular user (not Administrator) when installing Python packages. Running as Administrator can cause PATH issues that prevent anvyl from being recognized as a command.
Setup

Installing ANVYL

ANVYL is distributed as a standard Python package on PyPI. The entire installation is handled by pip — no compiling, no build tools, no configuration files needed.

1

Install Python 3.13+

Download the latest Python installer from python.org. Run the installer and on the first screen, check "Add Python to PATH" before clicking Install. This is the most common mistake — skipping it means your terminal won't find Python or pip after installation.

On macOS, you can also use Homebrew:

brew install python@3.13

On Ubuntu/Debian Linux:

sudo apt update sudo apt install python3.13 python3-pip
2

Open a terminal

On Windows, open PowerShell (search for it in the Start menu). On macOS, open Terminal (in Applications → Utilities). On Linux, use your system's terminal emulator.

Confirm Python is accessible by running python --version. You should see Python 3.13.x or higher. If you see an error, Python was not added to your PATH — re-run the installer and ensure the PATH checkbox is checked.

3

Install ANVYL via pip

Run the following command in your terminal:

pip install anvyl

pip will download ANVYL and all of its dependencies automatically. This typically takes 30–60 seconds depending on your connection speed. You will see a list of packages being installed — this is normal.

If pip is not found, try:

python -m pip install anvyl
4

Verify the installation

After installation completes, run:

anvyl --version

You should see the current version number printed to your terminal. If you see a "command not found" error, your Python scripts directory is not on your PATH. On Windows, this is typically C:\Users\YourName\AppData\Local\Programs\Python\Python313\Scripts. Add it to your PATH environment variable and restart your terminal.

5

Launch ANVYL

Run the command:

anvyl

The first time you launch ANVYL, a setup screen will appear. It will walk you through adding your Groq API key and connecting your Google account. Both steps are explained in detail below.

Keeping ANVYL up to date: New versions are released regularly with bug fixes and new features. To upgrade at any time, run: pip install --upgrade anvyl

Installing in a virtual environment (optional)

If you prefer to keep ANVYL isolated from your global Python environment, you can install it inside a virtual environment:

# Create a virtual environment python -m venv anvyl-env # Activate it (Windows PowerShell) anvyl-env\Scripts\Activate.ps1 # Activate it (macOS / Linux) source anvyl-env/bin/activate # Install ANVYL inside the venv pip install anvyl

When using a virtual environment, remember to activate it each time before running anvyl.

Uninstalling

To remove ANVYL from your system entirely:

pip uninstall anvyl

Your API keys (stored at ~/.anvyl/byok.json) and Google token (~/.anvyl/google_token.json) are not removed automatically. Delete the ~/.anvyl/ directory manually if you want a complete clean removal.

Setup

First Launch & Setup Screen

When you run anvyl for the first time, you will be greeted by the setup screen — a full-terminal UI that walks you through the initial configuration. You only need to complete this once.

What the setup screen does

  • Asks for your Groq API key (the only required key)
  • Optionally accepts additional provider keys (Google AI, Mistral, NVIDIA, etc.)
  • Prompts you to sign in with your Google account to unlock Gmail, Drive, and Workspace features
  • Saves everything locally to ~/.anvyl/ on your machine

Getting your Groq API key

Groq is the primary AI provider that powers ANVYL's main agent. It is free to use with generous rate limits.

1

Go to console.groq.com

Visit console.groq.com and create a free account. No credit card required.

2

Create an API key

Once logged in, go to API Keys in the left sidebar and click Create API Key. Give it a name (e.g. "ANVYL") and copy the key — you will only see it once.

3

Paste it into the setup screen

Back in ANVYL, paste the key into the Groq API Key field and press Continue. The key is saved to ~/.anvyl/byok.json and encrypted at rest.

Already past setup? You can open the key editor at any time from inside ANVYL by typing /keys. See the API Keys page for full details on all supported providers.
Setup

Google Sign-In

ANVYL integrates with your Google account to read and write Gmail, Google Drive, Docs, Sheets, Slides, Forms, and Calendar — all from your terminal. Google sign-in is set up during the initial setup screen, but you can skip it and connect later.

What Google access is used for

  • Gmail — Read inbox, search emails, summarize threads, list senders
  • Google Drive — List, read, and create files
  • Google Docs — Create and write documents using /docs
  • Google Sheets — Create spreadsheets using /sheets
  • Google Slides — Create presentations using /slides
  • Google Forms — Create forms using /forms
  • Google Calendar — Add events using /calendar

How authentication works

ANVYL uses Google's standard OAuth 2.0 flow. When you click "Sign in with Google" in the setup screen, ANVYL opens a browser tab pointing to Google's official sign-in page. You sign in to your Google account normally and grant ANVYL the requested permissions.

After you approve, Google sends an OAuth token back to ANVYL. This token is saved to ~/.anvyl/google_token.json on your machine. ANVYL never sees your Google password — it only receives the OAuth token.

1

Click "Sign in with Google" in the setup screen

ANVYL will open your default browser automatically and navigate to Google's sign-in page.

2

Sign in and grant permissions

Log in to your Google account and review the permissions ANVYL is requesting. These permissions cover Gmail read access, Drive access, and Workspace creation (Docs, Sheets, Slides, Forms, Calendar). Approve them to continue.

3

Token is saved automatically

After approving, the browser will show a success message and you can close the tab. The OAuth token is saved to ~/.anvyl/google_token.json. Future sessions authenticate silently — you will not be asked to sign in again unless the token expires.

4

Test the connection

Inside ANVYL, type /gmail to list your recent inbox. If you see your emails, everything is working correctly.

Re-authenticating and switching accounts

If your token expires or you want to switch to a different Google account, use the /sign-in command inside ANVYL. This opens a fresh OAuth flow and overwrites the saved token with the new one.

# Re-authenticate or switch accounts /sign-in # Revoke access and remove the token /sign-out

Revoking access

To completely remove ANVYL's access to your Google account, use /sign-out inside ANVYL, or go to myaccount.google.com/permissions and remove ANVYL from your connected apps. You can also delete the token file directly:

# Delete saved token manually ~/.anvyl/google_token.json (Mac/Linux) C:\Users\you\.anvyl\google_token.json (Windows)
Privacy note: Your Google credentials are stored only on your machine. ANVYL never transmits your token to any server other than Google's OAuth endpoints. See the Guidelines page for a full breakdown of what leaves your device.

Troubleshooting Google Sign-In

Browser doesn't open automatically — Copy the URL printed in the terminal and paste it into your browser manually.

"Access blocked" error from Google — ANVYL uses a development OAuth client. If you see an "unverified app" warning, click "Advanced" and then "Go to ANVYL (unsafe)" to proceed. This is a Google verification status for the app, not a security risk.

Token expired — Google OAuth tokens expire periodically. Run /sign-in to get a fresh token.

Wrong account signed in — Run /sign-out first, then /sign-in to switch accounts.

Setup

Running Your First Prompt

Once installation and setup are complete, you're ready to use ANVYL. Here's how to get going quickly.

Interactive mode

Just run anvyl with no arguments to open the interactive terminal UI. Type your prompt and press Enter to send it.

anvyl

Inline mode

You can also pass a prompt directly on the command line, which is useful for scripting or quick one-off tasks:

# Run a task directly from your terminal anvyl "summarize my last 5 emails" anvyl "create a Python script that renames all files in a folder" anvyl "search the web for the latest AI news"

Slash commands

Inside the interactive UI, type / to open the command palette. Use arrow keys to navigate suggestions and Tab to autocomplete. For a full list of available commands, see the Commands page.
