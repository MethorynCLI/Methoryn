Quick Start

Get Started with Methoryn

Methoryn is a multi-agent AI assistant that runs in your terminal. This page gets you from zero to your first prompt in under 5 minutes.

⬇ Download (.whl / .tar.gz) pip install Methoryn →

Download the .whl file from PyPI and install locally with pip install Methoryn-x.x.x-py3-none-any.whl — no internet required after download.

Overview

What is Methoryn?

Methoryn is a terminal application that connects multiple AI providers — Ollama (local) and Gemini (cloud) — into a single, unified assistant. You type a plain English prompt, and Methoryn figures out what to do: write code, manage files, summarize emails, create Google Docs, generate images, search the web, and more.

It runs entirely on your machine. There are no Methoryn servers, no accounts to create, and no data leaving your device except the prompts you send to AI providers directly.

What makes it different

  • Multi-agent — Different tasks are routed to the best-fit AI model automatically. You don't choose models; Methoryn does.
  • Terminal-native — Runs in your existing terminal. No browser, no Electron app, no GUI to install.
  • Google Workspace integration — Read your Gmail, create Docs, Sheets, Slides, and Calendar events from the command line.
  • File & code actions — Write files, run shell commands, and generate Python scripts without leaving your prompt.
  • Free to use — Every AI provider Methoryn connects to has a free tier. You can run Methoryn indefinitely without paying anything.

What Methoryn is not

  • It is not a chatbot — it's a task executor. It takes your prompt and does something with it.
  • It is not a cloud service — everything runs locally on your machine.
  • It is not a replacement for your IDE — it complements your existing tools.
Setup

5-Minute Setup

Choose your platform below — Windows, macOS, or Linux. Each path takes about 5 minutes from nothing to your first prompt.

Python 3.13+ is required. Methoryn uses libraries that depend on Python 3.13 features. Older versions will not work. The steps below show exactly how to get there on every platform — it takes about 2 minutes.
Recommended: Use uv for the most reliable installation. It downloads Python 3.13 automatically and creates an isolated environment, avoiding all the common version conflicts and PATH issues.

🎯 Recommended: uv (All Platforms)

This method works identically on Windows, macOS, and Linux. It automatically downloads Python 3.13 and avoids all the platform-specific version issues.

1

Install uv

Windows (PowerShell):

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

macOS / Linux:

curl -LsSf https://astral.sh/uv/install.sh | sh

Restart your terminal after installation.

2

Install Methoryn

uv tool install methoryn --python 3.13

This downloads Python 3.13 automatically and installs Methoryn in an isolated environment.

3

Launch

Methoryn

Note the capital M. Both Methoryn and methoryn work in v0.1.40+.

Alternative: Platform-Specific Methods

If you prefer to manage Python yourself or already have Python 3.13+ installed, use these platform-specific approaches:

🪟 Windows

1

Install Python 3.13

Download the latest Python 3.13 installer from python.org/downloads. Run it and make sure to check "Add Python to PATH" on the first screen — this is the most common mistake.

Verify in a new terminal window:

python --version # Should show Python 3.13.x or higher
Already have Python but the wrong version? Install 3.13 alongside it — multiple versions can coexist. Use py -3.13 --version (Python Launcher) to confirm 3.13 is available, then use py -3.13 -m pip install Methoryn instead of plain pip.
2

Install Methoryn

pip install Methoryn

If you have multiple Python versions, use:

py -3.13 -m pip install Methoryn
3

Launch

Methoryn

🍎 macOS (Intel & Apple Silicon)

macOS ships with Python 2 or an old Python 3 — never 3.13. You need to install it. The recommended method is Homebrew.

1

Install Homebrew (if you don't have it)

Open Terminal (search Spotlight with ⌘ Space → type Terminal) and paste:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Follow the prompts. Homebrew is the standard macOS package manager — it's safe and widely used.

2

Install Python 3.13

brew install python@3.13

After it finishes, Homebrew will print instructions to add Python to your PATH. Run the command it shows, which looks like:

# Apple Silicon Macs: echo 'export PATH="/opt/homebrew/opt/python@3.13/bin:$PATH"' >> ~/.zshrc source ~/.zshrc # Intel Macs: echo 'export PATH="/usr/local/opt/python@3.13/bin:$PATH"' >> ~/.zshrc source ~/.zshrc

Verify:

python3.13 --version # Should show Python 3.13.x
3

Install Methoryn

pip3.13 install Methoryn
pip not found? Use: python3.13 -m pip install Methoryn
4

Launch

Methoryn

If that doesn't work, try:

python3.13 -m Methoryn
macOS Gatekeeper: If you see a security warning the first time, go to System Settings → Privacy & Security and click "Allow Anyway". This is a one-time step for any new terminal tool.

🐧 Linux (Ubuntu / Debian / Fedora / Arch)

Most Linux distros ship with Python 3.11 or 3.12. You need 3.13.

1

Install Python 3.13

Ubuntu / Debian (deadsnakes PPA — easiest):

sudo apt update sudo apt install software-properties-common -y sudo add-apt-repository ppa:deadsnakes/ppa -y sudo apt update sudo apt install python3.13 python3.13-venv python3.13-dev -y

Fedora:

sudo dnf install python3.13

Arch Linux:

sudo pacman -S python

Verify:

python3.13 --version
2

Install pip for Python 3.13

curl -sS https://bootstrap.pypa.io/get-pip.py | python3.13

Or on Ubuntu/Debian:

sudo apt install python3.13-pip
3

Install Methoryn

python3.13 -m pip install Methoryn
4

Launch

Methoryn

If the command isn't found, add ~/.local/bin to your PATH:

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc source ~/.bashrc Methoryn

After Install (all platforms)

A

Install Ollama

Go to ollama.com/download and install Ollama for your platform. It runs Qwen 2.5 Coder locally on your machine - no API key needed.

After installing, pull the required models:

ollama pull qwen2.5-coder
100% local: Ollama runs entirely on your machine. Your prompts never leave your device for the Methoryn Agent.
B

Complete setup on first launch

Run Methoryn - the first launch opens a setup screen. Enter your Google API key (Gemini) for the Architect agent and sign in with Google to unlock Gmail and Workspace features. The Methoryn Agent uses Ollama locally - no keys needed.

C

Run your first prompt

summarize my last 5 emails
write a Python script that lists all files in a folder by size
search the web for the latest AI news
Already installed? To update: pip install --upgrade Methoryn (or pip3.13 install --upgrade Methoryn on macOS/Linux)
Troubleshooting

Installation Troubleshooting

If you hit issues during installation, here are the most common problems and their fixes:

❌ "Command not found: methoryn"

Cause: The command is Methoryn (capital M), not methoryn.

Fix: Type Methoryn instead. As of version 0.1.40+, both Methoryn and methoryn work.

❌ "No matching distribution found for Methoryn"

Cause: Your Python version is older than 3.13. Methoryn requires Python 3.13+ and pip shows this confusing error instead of saying "wrong Python version."

Fix: Check your Python version with python --version. If it's 3.12 or older, follow the Python 3.13 installation steps above for your platform.

❌ "Methoryn --help" hangs or shows weird characters

Cause: In versions before 0.1.40, Methoryn launches the full TUI immediately — there's no traditional --help text output.

Fix: This is normal behavior. To verify Methoryn is installed correctly, use:

# Check if installed pip list | grep -i methoryn # Or with uv uv tool list

❌ macOS: "Methoryn cannot be opened because the developer cannot be verified"

Cause: macOS Gatekeeper blocks unsigned terminal applications on first run.

Fix: Go to System Settings → Privacy & Security and click "Allow Anyway" next to the blocked app. This is a one-time step.

❌ Windows: Multiple Python versions, wrong one used

Cause: You have multiple Python installations and pip is using an older version.

Fix: Use Python Launcher to target 3.13 specifically:

# Check what Python versions you have py --list # Install with Python 3.13 specifically py -3.13 -m pip install Methoryn # Run with Python 3.13 py -3.13 -m Methoryn

❌ Linux: PATH issues, command not found after successful install

Cause: pip installed Methoryn to ~/.local/bin but that directory isn't in your PATH.

Fix: Add ~/.local/bin to your PATH:

# Add to your shell config (.bashrc, .zshrc, etc.) echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc source ~/.bashrc # Then try again Methoryn

❌ "pip: command not found" (macOS/Linux)

Cause: pip isn't installed for Python 3.13, or you're using the wrong pip.

Fix: Use the Python module syntax:

python3.13 -m pip install Methoryn

❌ Installation succeeds but API key setup fails

Cause: Network issues, wrong API key format, or provider API changes.

Fix: Check that your Google API key is valid for Google AI Studio and test it manually:

curl -X POST "https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent?key=YOUR_GOOGLE_KEY" \ -H "Content-Type: application/json" \ -d '{"contents":[{"parts":[{"text":"hello"}]}]}'

Alternative Installation Method (uv)

If standard pip installation fails, try uv — it downloads its own Python 3.13 and creates isolated environments:

# Install uv (one-time setup) curl -LsSf https://astral.sh/uv/install.sh | sh # Install Methoryn with private Python 3.13 uv tool install methoryn --python 3.13 # Run Methoryn

This method bypasses all Python version and PATH issues. It's what worked on the macOS test machine in the bug report.

What to Expect

Response time

Most prompts take 2–8 seconds to complete. Longer tasks — like creating a full Google Slides deck or writing a multi-file Python project — can take 15–30 seconds. Methoryn shows a spinner while it's working.

Token usage

Every prompt uses tokens from your AI provider accounts. Here's a rough guide to how much a typical prompt costs:

Task typeApprox. tokensImpact on free tier
Simple question or lookup100–300Negligible
Summarize emails or a document500–1,500Very low
Write a Python script800–2,000Low
Create a Google Slides deck (10 slides)2,000–5,000Moderate
Complex multi-step task3,000–8,000Moderate

Ollama (Methoryn Agent): Runs locally on your machine - completely free, unlimited usage. Gemini (Architect agent): Free tier covers typical usage. Longer or more complex tasks may require a paid plan for heavy use.

What Methoryn can and can't do

Methoryn is very capable within its scope, but it has limits:

  • Can do: Anything described on this site — files, code, web, Google Workspace, images
  • Can't do: Access files, accounts, or services you haven't connected
  • Can't do: Make payments, purchases, or interact with services that require authentication beyond what you've set up
Important

What Not to Share with AI

Because your prompts are sent to third-party AI providers (Gemini, etc.), be mindful of what you include in them. The AI providers receive the full text of every prompt you type.

Never include in a prompt:
  • Passwords or PINs
  • Credit card or bank account numbers
  • Social security or national ID numbers
  • Private API keys or secret tokens (ironic as that sounds)
  • Confidential business data, trade secrets, or NDA-protected information
  • Medical records or health information
  • Personal information belonging to other people without their consent

Why this matters

Methoryn itself never stores your prompts. But the AI providers — Google (Gemini) and your local Ollama instance — receive them as part of generating responses. Gemini has its own data retention and training policies. Ollama keeps everything local. Sensitive data sent to cloud providers could be logged, retained, or used to improve their models depending on the provider's current policy.

For full details on what data leaves your machine and where it goes, see the Privacy section.

Safe ways to work with sensitive context

If you need Methoryn to work with sensitive data, describe it in general terms rather than including the actual values:

# Instead of this: my credit card number is 4111 1111 1111 1111, help me track spending # Do this: help me build a spreadsheet to track my monthly credit card spending by category
