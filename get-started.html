Quick Start

Get Started with CORVUS

CORVUS is a multi-agent AI assistant that runs in your terminal. This page gets you from zero to your first prompt in under 5 minutes.

Overview

What is CORVUS?

CORVUS is a terminal application that connects multiple AI providers — Groq, Gemini, Mistral, and others — into a single, unified assistant. You type a plain English prompt, and CORVUS figures out what to do: write code, manage files, summarize emails, create Google Docs, generate images, search the web, and more.

It runs entirely on your machine. There are no CORVUS servers, no accounts to create, and no data leaving your device except the prompts you send to AI providers directly.

What makes it different

  • Multi-agent — Different tasks are routed to the best-fit AI model automatically. You don't choose models; CORVUS does.
  • Terminal-native — Runs in your existing terminal. No browser, no Electron app, no GUI to install.
  • Google Workspace integration — Read your Gmail, create Docs, Sheets, Slides, and Calendar events from the command line.
  • File & code actions — Write files, run shell commands, and generate Python scripts without leaving your prompt.
  • Free to use — Every AI provider CORVUS connects to has a free tier. You can run CORVUS indefinitely without paying anything.

What CORVUS is not

  • It is not a chatbot — it's a task executor. It takes your prompt and does something with it.
  • It is not a cloud service — everything runs locally on your machine.
  • It is not a replacement for your IDE — it complements your existing tools.
Setup

5-Minute Setup

Here's the complete path from nothing to a working CORVUS install. Each step takes about a minute.

1

Install Python 3.13+

Download from python.org. On Windows, check "Add Python to PATH" during installation — this is the most common setup mistake. On macOS, use Homebrew: brew install python@3.13.

Verify it worked:

python --version # Should show Python 3.13.x or higher
2

Install CORVUS

pip install CORVUS

This downloads CORVUS and all its dependencies from PyPI. Takes about 30–60 seconds.

3

Get a free Groq API key

Go to console.groq.com, create a free account (no credit card), and generate an API key. Copy it — you'll need it in the next step.

Free tier: Groq gives you 12,000 tokens per minute at no cost. For reference, a typical CORVUS prompt uses 200–800 tokens. You won't hit limits in normal use.
4

Launch CORVUS and complete setup

CORVUS

The first launch opens a setup screen. Paste your Groq API key and press Continue. Optionally sign in with Google to unlock Gmail and Workspace features. That's it — setup is done.

5

Run your first prompt

Type anything and press Enter:

summarize my last 5 emails
write a Python script that lists all files in a folder by size
search the web for the latest AI news

Or type / to open the command palette and browse everything CORVUS can do.

Already installed? To update to the latest version: pip install --upgrade CORVUS
Overview

What to Expect

Response time

Most prompts take 2–8 seconds to complete. Longer tasks — like creating a full Google Slides deck or writing a multi-file Python project — can take 15–30 seconds. CORVUS shows a spinner while it's working.

Token usage

Every prompt uses tokens from your AI provider accounts. Here's a rough guide to how much a typical prompt costs:

Task typeApprox. tokensGroq free tier impact
Simple question or lookup100–300Negligible
Summarize emails or a document500–1,500Very low
Write a Python script800–2,000Low
Create a Google Slides deck (10 slides)2,000–5,000Moderate
Complex multi-step task3,000–8,000Moderate

Groq's free tier is 12,000 tokens per minute (TPM). This resets every minute, so even heavy use rarely hits the limit unless you are running rapid-fire automated prompts.

What CORVUS can and can't do

CORVUS is very capable within its scope, but it has limits:

  • Can do: Anything described on this site — files, code, web, Google Workspace, images
  • Can't do: Access files, accounts, or services you haven't connected
  • Can't do: Remember previous sessions (unless you load a saved session with /save)
  • Can't do: Make payments, purchases, or interact with services that require authentication beyond what you've set up
Important

What Not to Share with AI

Because your prompts are sent to third-party AI providers (Groq, Gemini, Mistral, etc.), be mindful of what you include in them. The AI providers receive the full text of every prompt you type.

Never include in a prompt:
  • Passwords or PINs
  • Credit card or bank account numbers
  • Social security or national ID numbers
  • Private API keys or secret tokens (ironic as that sounds)
  • Confidential business data, trade secrets, or NDA-protected information
  • Medical records or health information
  • Personal information belonging to other people without their consent

Why this matters

CORVUS itself never stores your prompts. But the AI providers — Groq, Google, Mistral — receive them as part of generating responses. Each provider has its own data retention and training policies. Sensitive data in prompts could be logged, retained, or used to improve their models depending on the provider's current policy.

For full details on what data leaves your machine and where it goes, see the Privacy section.

Safe ways to work with sensitive context

If you need CORVUS to work with sensitive data, describe it in general terms rather than including the actual values:

# Instead of this: my credit card number is 4111 1111 1111 1111, help me track spending # Do this: help me build a spreadsheet to track my monthly credit card spending by category
