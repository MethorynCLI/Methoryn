Commands & Keybindings

Complete reference for every slash command Methoryn supports, all keyboard shortcuts, and a library of example prompts to get the most out of the tool.

Usage

The Command Palette

Methoryn's slash command system is built around a live command palette. Type / anywhere in the prompt input to open it. As you keep typing after the slash, the list filters in real time to matching commands.

How to use it

  • Type / to open the palette and see all available commands
  • Continue typing to filter — /doc narrows down to /docs, /desktop, etc.
  • Use ↑ and ↓ arrow keys to move through the suggestion list
  • Press Tab to autocomplete the highlighted command into the input
  • Press Enter to execute the selected command
  • Press Escape to close the palette without executing

Commands with arguments

Some commands accept an inline argument after the command name. For example:

# Search the web for a specific query /search latest news on AI regulation # Fetch and read a specific URL /fetch https://example.com/article # Generate an image from a description /image a red fox sitting in a snowy forest at dusk

For commands that create files or documents, Methoryn will ask you for content via a follow-up prompt if you do not provide it inline.

Local File Operations

Keyboard Shortcuts

Methoryn is designed to be fully keyboard-driven. These shortcuts work anywhere inside the Methoryn terminal UI.

KeyActionNotes
Enter Send the current prompt Submits whatever is in the input box
Shift + Enter Insert a new line Lets you write multi-line prompts before sending
/ Open the command palette Type at the start of a prompt to trigger slash commands
↑ ↓ Navigate palette suggestions Move up and down through the filtered command list
Tab Autocomplete selected command Fills the highlighted command into the input box
Escape Close the command palette Returns to normal input mode without executing anything
Ctrl + Y Copy all output to clipboard Same as running /copy
Ctrl + S Save session to disk Same as running /save — saves to sessions/ folder
Ctrl + C Quit Methoryn Shows a confirmation prompt before exiting

Multi-line prompts

For complex tasks, you can write multi-line prompts using Shift + Enter to insert line breaks. This is useful when you want to give Methoryn a detailed set of instructions or paste a block of text to work with.

# Example multi-line prompt (use Shift+Enter between lines) Write a Python script that: - Reads all .txt files in the current folder - Counts the word frequency in each file - Saves a summary CSV with columns: filename, top_word, count

Combining tasks

Methoryn can chain multiple actions together in a single prompt. The agent breaks down complex requests into steps and executes them in sequence.

search for the top AI tools of 2026, write a summary, create a Google Doc with the results, and save the doc link to a file called ai-tools.txt
summarize my last 5 emails, format the summaries as bullet points, and create a Google Slides presentation with one slide per email
write a Python script that generates a random password, run it, and save the output to passwords.txt
Tips for better results: Be specific about format, length, and style. "Write a 500-word blog post in a casual tone about Python type hints" gets better results than "write about Python." For file creation tasks, include the filename in your prompt so Methoryn knows where to save it.
