Configuration

API Keys

Methoryn connects to multiple AI providers. Only one key is required to get started — everything else is optional and unlocks additional capabilities.

Overview

How Keys Work in Methoryn

Methoryn is a multi-agent system. Different tasks are routed to different AI providers depending on what produces the best result. The main task agent runs on Groq. Sub-agents and specialized tasks can use Gemini, Mistral, NVIDIA NIM, OpenRouter, and HuggingFace as fallbacks or primaries depending on availability.

The key hierarchy

Methoryn checks for API keys in this order:

  1. Keys saved in the in-app key editor (~/.Methoryn/byok.json)
  2. Environment variables set in your shell session
  3. A .env file in the directory where you run Methoryn

The in-app editor (recommended) takes priority over everything else. This means you can override a key for a single session by setting an environment variable, without permanently changing your saved configuration.

Where keys are stored

Keys saved through the in-app editor are written to ~/.Methoryn/byok.json on your machine. This file is local only — it is never transmitted to Methoryn servers or any third party. The only time a key leaves your machine is when Methoryn makes a direct API call to the provider that key belongs to.

Free tiers only: Every provider listed on this page offers a free tier with no credit card required. You can run Methoryn at full capability without spending anything.
Required

Groq API Key

The Groq API key is the only key Methoryn requires. It powers the main task agent — the one that receives your prompts, reasons through them, and decides what actions to take. Without it, Methoryn cannot run.

Getting your Groq key

1

Create a free account at console.groq.com

Go to console.groq.com and sign up. No credit card required. Groq's free tier is generous — 12,000 tokens per minute on their fastest models.

2

Create an API key

In the Groq Console, click API Keys in the left sidebar, then Create API Key. Name it anything (e.g. "Methoryn") and click Create. Copy the key immediately — Groq only shows it once.

3

Add it to Methoryn

If you are in the setup screen, paste it into the Groq API Key field. If Methoryn is already running, type /keys to open the key editor, find the GROQ_API_KEY field, and paste your key there.

Groq rate limits (free tier)

Groq's free tier provides:

  • 12,000 tokens per minute (TPM)
  • No daily or monthly hard cap on the free tier
  • Access to Llama 3.3 70B, Llama 3.1 8B, Mixtral 8x7B, and more

For most personal use cases, the free tier is more than sufficient. If you hit rate limits during heavy use, Methoryn will automatically throttle requests and retry.

Google AI Studio (Gemini)

The Google API key from AI Studio is separate from your Google account sign-in. The Google Sign-In (OAuth) connects Methoryn to your Gmail, Drive, and Workspace. The Google AI Studio key connects Methoryn to the Gemini model API for AI inference. You need both if you want both Google Workspace integration and Gemini-powered sub-agents.

To get a Google AI Studio key, go to aistudio.google.com/app/apikey, sign in with your Google account, and click Create API key. The free tier gives you 1 million tokens per minute — effectively unlimited for personal use.

Mistral

Mistral provides some of the best open-weight models available. Methoryn uses Mistral for its chat agent — conversational tasks, explanations, and writing. The free tier is very generous at approximately 1 billion tokens per month. Sign up at console.mistral.ai.

OpenRouter

OpenRouter is a unified API that routes requests to dozens of AI providers and models. Methoryn uses it as a fallback when other sub-agents are unavailable or rate-limited. With one OpenRouter key, you get access to GPT-4o, Claude, Gemini, Llama, and many others. Free tier gives 50 requests per day. Sign up at openrouter.ai.

Pollinations.ai

Image generation via /image uses Pollinations.ai and does not require an API key at all. It is free and open by default. The pollinations.ai_API_KEY field exists for future use if Pollinations introduces authenticated tiers.

Configuration

Managing Your Keys

Methoryn gives you three ways to manage API keys. The in-app editor is the recommended method for most users.

Method 1: In-app key editor (recommended)

Type /keys from anywhere inside Methoryn to open the full key editor UI. It shows all supported providers, their current status (set / not set), and lets you add, edit, or remove keys without touching any files.

/keys

Changes made in the key editor take effect immediately — no restart required. Keys are written to ~/.Methoryn/byok.json.

Method 2: Environment variables

You can set keys as environment variables in your shell. This is useful for CI/CD pipelines or if you prefer not to store keys in a file.

# Windows PowerShell $env:GROQ_API_KEY = "gsk_your_key_here" # macOS / Linux (bash/zsh) export GROQ_API_KEY="gsk_your_key_here" # Then launch Methoryn in the same session Methoryn

Environment variables are session-scoped — they disappear when you close your terminal. To make them permanent, add the export line to your shell profile (~/.zshrc, ~/.bashrc, or Windows system environment variables).

Method 3: .env file

Create a file named .env in the directory where you run Methoryn. Methoryn will load it automatically on startup.

# .env file — one key per line GROQ_API_KEY=gsk_your_key_here GOOGLE_API_KEY=AIzaSy_your_key_here MISTRAL_API_KEY=your_key_here
Warning: Never commit your .env file or byok.json to a public git repository. Add both to your .gitignore. Your API keys will be immediately harvested by bots if exposed in a public repo.

Checking key status

Inside Methoryn, run /keys to see which keys are currently configured. The editor shows a green indicator next to each key that is set and a grey indicator for keys that are missing.

Removing a key

Open /keys, navigate to the key you want to remove, clear the field, and save. Alternatively, edit ~/.Methoryn/byok.json directly in any text editor and delete the relevant line.

Key file location

# macOS / Linux ~/.Methoryn/byok.json # Windows C:\Users\YourName\.Methoryn\byok.json
Tips

Managing Your Credit Usage

Every AI provider counts usage in tokens. Understanding how tokens work helps you stay well within free tier limits and avoid unexpected rate limit errors.

What is a token?

A token is roughly 3/4 of a word. The sentence "pip install Methoryn" is about 4 tokens. A full email summary prompt might be 500–2,000 tokens including the response. Tokens count for both your input (the prompt) and the output (the AI's response).

Free tier limits by provider

ProviderFree limitResetsBest used for
Groq 12,000 TPM Every minute Main agent — all tasks
Google AI Studio (Gemini) 1,000,000 TPM Every minute Long-context, reasoning tasks
Mistral ~1B tokens/month Monthly Chat, writing, explanations
NVIDIA NIM 40 RPM Per minute Chat backup
OpenRouter 50 req/day Daily Fallback routing
HuggingFace Varies by model Monthly Open-source model backup

Tips for staying within free limits

  • Be specific in prompts — A focused prompt generates a tighter response and uses fewer tokens than a vague one that produces a long, hedged answer.
  • Avoid sending large files as prompts — If you need Methoryn to work with a large document, describe its structure rather than pasting the entire contents.
  • Add a second provider — With both Groq and Gemini keys set, Methoryn can route heavy tasks to Gemini's 1M TPM free tier, keeping Groq headroom available.
  • Check usage in the provider console — Groq shows your usage at console.groq.com. Check it periodically if you use Methoryn heavily.
  • Don't loop Methoryn in scripts — Running Methoryn in a loop (e.g. calling it 50 times in a bash script) can exhaust Groq's 12K TPM limit in seconds. Add delays if you automate Methoryn.

What not to include in prompts

Since prompts are sent to AI providers, be careful about what you include:

Avoid including in any prompt: passwords, credit card numbers, social security numbers, private API keys, confidential business data, medical records, or personal information belonging to others. AI providers receive the full text of every prompt and may log or retain it per their own policies.

See the Privacy section for a full breakdown of what each provider receives.

Help

Troubleshooting API Keys

"Invalid API key" error

Double-check that you copied the full key without any leading or trailing spaces. API keys from most providers start with a specific prefix (Groq keys start with gsk_, Google AI Studio keys start with AIzaSy). If the key looks correct, try regenerating it in the provider's console — a freshly generated key eliminates the possibility of a partially expired or revoked key.

"Rate limit exceeded" error

You have hit the free tier's request limit for that provider. Methoryn will automatically retry with a short delay. If you consistently hit rate limits, consider adding a second provider key as a fallback. For example, adding a Mistral key alongside your Groq key gives Methoryn an alternative to fall back on during Groq rate limit windows.

Keys not being picked up from .env

Make sure the .env file is in the same directory you run Methoryn from, not your home directory or a subdirectory. The file must be named exactly .env (with the leading dot). Also confirm there are no spaces around the = sign in the file.

Key works in browser but not in Methoryn

Some providers (like Groq) show a preview of the key in their console that is truncated. Make sure you clicked "Copy" to get the full key, not selected the truncated text manually. Also check that Methoryn's byok.json contains the complete key — open it in a text editor to verify.
