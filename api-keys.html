API Keys

Methoryn runs locally via Ollama (no keys needed) and uses Gemini via a single API key. Every provider offers a free tier.

Overview

How Keys Work

Methoryn is a two-agent system. The Methoryn Agent runs locally through Ollama — no API keys required, Ollama is auto-installed. Architect uses Google AI Studio (Gemini) for image generation and requires a single API key. Google Workspace integration (Gmail, Drive, Docs, Sheets, Slides) uses separate OAuth credentials managed via /account.

Where keys are stored

Keys saved through the in-app editor are written to ~/.Methoryn/byok.json on your machine. This file is local only — it is never transmitted to Methoryn servers or any third party. The only time a key leaves your machine is when Methoryn makes a direct API call to the provider that key belongs to.

Required

Google API Key

The Google API key powers Architect — the research and multimodal agent. It is the only key required to run Methoryn at full capability.

Getting your Google AI Studio key

1

Go to Google AI Studio

Navigate to aistudio.google.com/app/apikey and sign in with your Google account. No credit card required.

2

Create an API key

Click Create API key. Name it anything (e.g. "Methoryn"). Copy the key — it starts with AIzaSy.

3

Add it to Methoryn

If you are in the setup screen, paste it into the Google API Key field. If Methoryn is already running, type /account to open the account manager, find the GOOGLE_API_KEY field, and paste your key there.

Local AI

Ollama Setup

The Methoryn Agent (Qwen 2.5 Coder 3B) runs locally through Ollama - no API keys, no rate limits, fully private. Ollama is auto-installed on first launch — you don't need to set it up manually.

What happens on first launch

  1. Methoryn checks if Ollama is installed
  2. If not found, it auto-installs Ollama (Windows) or guides you through installation (macOS/Linux)
  3. Downloads the Qwen 2.5 Coder model (~2 GB, one-time)
  4. Warms up the model for fast first response

Manual installation (optional)

If you prefer to install Ollama yourself, download from ollama.com/download. Works on Windows, macOS, and Linux.

ollama pull qwen2.5-coder # Pre-pull to skip download on first launch
Configuration

Managing Your Keys

Methoryn gives you three ways to manage API keys. The in-app editor is the recommended method for most users.

Method 1: In-app account & key editor (recommended)

Type /account from anywhere inside Methoryn to open the account manager — it handles both API keys and Google accounts (add / remove / switch). Changes take effect immediately with no restart.

/account

Keys are stored locally at ~/.Methoryn/byok.json.

Method 2: Environment variables

# Windows PowerShell $env:GOOGLE_API_KEY = "AIzaSy_your_key_here" # macOS / Linux (bash/zsh) export GOOGLE_API_KEY="AIzaSy_your_key_here" # Then launch Methoryn in the same session Methoryn

Environment variables are session-scoped. To make them permanent, add the export line to your shell profile (~/.zshrc, ~/.bashrc, or Windows system environment variables).

Method 3: .env file

Create a file named .env in the directory where you run Methoryn.

# .env file — one key per line GOOGLE_API_KEY=AIzaSy_your_key_here
Warning: Never commit your .env file or byok.json to a public git repository. Add both to your .gitignore.

Checking key status

Inside Methoryn, run /account to see which keys are currently configured.

Key file location

# macOS / Linux ~/.Methoryn/byok.json # Windows C:\Users\YourName\.Methoryn\byok.json

Help

Troubleshooting

"Invalid API key" error

Double-check you copied the full key without spaces. Google AI Studio keys start with AIzaSy. Try regenerating in the console if the key looks correct.

Ollama not responding

Make sure Ollama is running (ollama serve) and the model is pulled (ollama pull qwen2.5-coder).

Keys not being picked up from .env

Make sure the .env file is in the same directory you run Methoryn from. The file must be named exactly .env with no spaces around the = sign.
