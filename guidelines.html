How Methoryn is intended to be used, exactly what data leaves your machine, and the terms under which it is distributed.

Guidelines

Usage Guidelines

Methoryn is a general-purpose AI assistant that runs on your machine and connects to external AI providers and your Google account. With that access comes responsibility. These guidelines describe how Methoryn is intended to be used and where the boundaries are.

What Methoryn is designed for

Methoryn is built for personal productivity — automating tasks you would otherwise do manually, writing and running code, and interacting with the tools and services you already use.

  • Automating repetitive tasks like file management, renaming, sorting, and organizing
  • Drafting and generating documents, spreadsheets, presentations, and reports
  • Writing, testing, and running Python scripts and shell commands on your machine
  • Reading and summarizing your own Gmail, Drive files, and calendar events
  • Searching the web and synthesizing information into usable output
  • Generating images for personal or creative projects
  • Any task you would normally do yourself in a terminal, browser, or office application

What Methoryn should not be used for

The following uses are prohibited and will likely result in your API keys being suspended by the affected providers:

  • Accessing accounts, files, email, or systems you do not own or have explicit permission to access
  • Sending unsolicited emails, automated spam, or bulk messages without recipient consent
  • Generating malicious code, exploits, ransomware, or other harmful software
  • Scraping websites in violation of their terms of service
  • Any activity that violates the terms of service of Google
  • Generating content that is illegal in your jurisdiction
  • Impersonating individuals or organizations

Use with care

Some of Methoryn's capabilities act directly on your machine or accounts with no undo. Be mindful with these:

/run — Shell commands
Methoryn executes shell commands directly on your machine. A bad command can delete files, modify system settings, or consume resources. Always review the command before pressing Enter. If you are not sure what a command does, ask Methoryn to explain it first before running it.
/write and file output commands
File writes are immediate and will silently overwrite an existing file at the same path. There is no recycle bin — the original content is gone. Include a unique name or path in your prompt to avoid accidental overwrites.
Gmail actions
If Methoryn reads your Gmail, it does so with the OAuth permissions you granted. Methoryn does not delete or send emails unless you explicitly ask it to with a prompt like "send an email to..." or "delete emails from...". Actions on email are permanent — there is no undo for sends or deletes.
API key consumption
Every prompt you send consumes tokens from your provider accounts. On free tiers, this is essentially unlimited for normal use. If you run automated scripts or loops that call Methoryn repeatedly, monitor your usage in each provider's console to avoid unexpectedly exhausting your quota.

Responsible use

Methoryn connects to real services with real consequences. Treat it the same way you would treat yourself sitting at a terminal with access to your email, files, and Google account. The tool is as powerful as the person using it.

If you find a bug, unexpected behavior, or a way Methoryn does something it shouldn't, please report it at Anvyl.cli@gmail.com.

Privacy

Privacy

Methoryn is installed and runs entirely on your machine. There are no Methoryn servers, no telemetry, no analytics, and no account system. Here is the complete picture of what leaves your device when you use Methoryn.

What leaves your machine

WhatSent toWhyCan you opt out?
Your prompts and conversation history Methoryn Agent or Architect - whichever agent handles your request To generate AI responses Only by not using Methoryn
Google OAuth token (not your password) Google OAuth servers To authenticate your Google account and access Gmail, Drive, etc. Yes — open /account and remove the account
Image generation prompts Google Gemini API To generate images when you use /image Yes — don't use /image
URLs you provide to /fetch The target URL's server To fetch the page content you requested Yes — don't use /fetch
Search queries from /search The search provider used internally To return web search results Yes — don't use /search

What stays on your machine

  • Your API keys — stored in ~/.Methoryn/byok.json, never transmitted to anyone except the provider the key belongs to
  • Your Google OAuth tokens — stored per account in ~/.Methoryn/tokens/ with your account list in ~/.Methoryn/accounts.json, only sent to Google's OAuth endpoint during authentication
  • Session files — saved locally in the sessions/ folder via /save and automatically on quit
  • Generated files — all output from /write, /python, /pdf, etc. is saved to your local machine only
  • Your file system — Methoryn only reads or writes files when you explicitly ask it to

Methoryn does not collect

  • Usage analytics or telemetry
  • Crash reports
  • Prompt history sent to any Methoryn-controlled server (there are none)
  • Personal information of any kind
  • Device identifiers or IP addresses

Third-party provider privacy policies

Your prompts are processed locally by Ollama (Methoryn Agent) or sent to Google's Gemini API (Architect agent for images). Ollama runs entirely on your machine and does not send any data externally. Only the Architect agent sends prompts to Google. Methoryn has no control over how Google handles the data you send them. Review their policy if this is a concern:

  • Google Privacy Policy

Sensitive data in prompts

Because your prompts are sent to third-party AI providers, avoid including sensitive personal information in prompts where possible — things like passwords, social security numbers, financial account numbers, or confidential business data. Methoryn cannot prevent that information from being transmitted to the AI provider handling your request.

Local-first by design: Methoryn was built so that your files, keys, and tokens stay on your machine. The only data that leaves is what's necessary to make the AI work — your prompts. Everything else is local.
Privacy

Local Data Storage

Methoryn stores a small number of files on your machine in the ~/.Methoryn/ directory. Here is exactly what is stored and how to manage it.

File locations

FileContentsHow to remove
~/.Methoryn/byok.json Your API keys for all configured providers Delete the file, or clear keys via /account
~/.Methoryn/accounts.json + tokens/ Your Google account list and per-account OAuth tokens (not your password) Remove accounts via /account, or delete the files manually
sessions/ Saved session files from /save (JSON format) Delete individual files or the whole folder
outputs/ Generated images and other output files Delete individual files or the whole folder

Complete removal

To fully remove all Methoryn data from your machine:

# Uninstall the package pip uninstall Methoryn # Remove all Methoryn data (Mac/Linux) rm -rf ~/.Methoryn # Remove all Methoryn data (Windows PowerShell) Remove-Item -Recurse -Force "$env:USERPROFILE\.Methoryn"
